# PLEBS email lifecycle

The application keeps branded React Email source under
`src/lib/email/templates/`. Fourteen matching templates are published in
Resend and use stable aliases from `src/lib/email/template-aliases.ts`. Website
triggers send those aliases through the shared Resend adapter, so the delivered
message is the published template visible in the Resend dashboard.

## Brand system

- Forest, moss, sand and cream colours match the website design tokens.
- The email-safe logo is PNG because SVG support is inconsistent across inboxes.
- Editorial and product images are JPEG for broad Outlook, Gmail and Apple Mail
  support.
- Source assets are generated by `npm run media:prepare`.
- Production image URLs use `https://www.plebs.co.za/images/email/`.
- `npm run email:render` renders all templates to the ignored
  `.email-previews/` directory for local review.
- `npm run email:export` creates ignored payload files for review.
- `npm run email:sync` updates and publishes all dashboard templates when run
  with a full-access Resend management key. The production website key may
  remain send-only.

## Active transactional sends

- Contact form: `plebs-contact-owner` sends the full enquiry to the owner and
  `plebs-contact-received` confirms receipt to the customer.
- Paid order: sends one combined PLEBS payment and order confirmation to the
  customer through `plebs-order-confirmed`, plus
  `plebs-order-owner` internally. Paystack may separately send its own payment
  receipt.
- Restock request: `plebs-restock-requested` confirms the exact colour and size.
- Dispatch: `plebs-shipping-confirmation` sends courier and tracking information
  when an administrator marks an order fulfilled.
  `Fulfilment.customerNotifiedAt` and the Resend idempotency key prevent
  duplicate notices.

## Ready templates without automatic sends

- Newsletter subscription welcome.
- Newsletter news/update edition.
- Editorial or campaign announcement.
- Abandoned checkout reminder.
- Back-in-stock alert.
- Refund confirmation.
- Unpaid order cancellation.
- Owner return/exchange request notification.

These templates are published and ready in Resend, but are intentionally not
attached to an unsafe or incomplete trigger.

## Marketing requirements before activation

- The Resend topic `PLEBS news & updates` exists with a default `opt_out`
  subscription. A signup must explicitly opt the contact into this topic.
- Newsletter signup needs a server endpoint that records the consent timestamp,
  source and exact wording before adding the address to Resend.
- The marketing footer needs the business postal address before the first
  campaign is sent.
- Every Broadcast must target the newsletter segment and topic and must retain
  the `{{{RESEND_UNSUBSCRIBE_URL}}}` link.
- Abandoned-checkout email is direct marketing. Do not schedule it until
  checkout captures a separate, unticked cart-reminder consent and stores proof
  of that consent.
- Back-in-stock alerts may only be sent for the colour and size explicitly
  requested. The current restock model already keeps this scope separate from
  general marketing consent.
